# Claims and evidence map (preprint, November 2026)

Every central claim of the paper (abstract Results and Conclusions, the Contributions list, each RQ verdict, every figure in the
"results at a glance" table and the Conclusion), mapped to the file in this repository where the figure appears.
Paths are relative to the repository root. `file:N` is a line number; a JSON key path is given where it is more stable.
Sections are named by their label in the manuscript (line numbers in the manuscript are not used). The same figures, computed from the evidence files, are in `paper/results/numbers.json`.

State:
- **recomputed**: regenerated by `python3 reproduce.py` from public data and compared byte for byte with the committed file
  (RQ1 primary and D51 analyses need a git clone with the frame commit).
- **saved**: compared with a saved result (`reproduce.py` checks it against a stored value, e.g. the drand beacon).
- **private**: the committed output is public, but its inputs need private data not in this tree.
- **documented**: read from an evidence table, capture or README; not regenerated by `reproduce.py` (post hoc scripts that exist
  are named in the row).

Short names used below: `RQ1A` = `preregistration/runs/rq1-confirmatory-20261027T142818Z-rq1-analysis`;
`SA` = `preregistration/rq1/source-audit-posthoc`; `Q2E` = `trusting-a-repo/evidence`; `Q3E` = `tool-change/evidence/primary-20261015`;
`Q4R` = `defence-coverage/results-20261024`; `Q5S` = `telemetry/evidence/scores-20261024`.
